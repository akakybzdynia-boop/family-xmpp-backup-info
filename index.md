# Family XMPP Backup

Family XMPP Backup is a private backup utility operated by the owner of a Google
Drive account. It uses restic and rclone to store encrypted backups of a personal
XMPP server in that account.

The utility creates, reads, updates and deletes its own backup files in Google
Drive. Backup content is encrypted on the source server before upload.
It is not a public service and does not offer registration to other users.

This website provides information for the Google OAuth consent screen. It does
not contain backups, server credentials or a sign-in form.
